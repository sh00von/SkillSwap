# SkillSwap

A peer-to-peer platform where people exchange skills — teach what you know, learn what you don't. No money, just knowledge.

## Features

- Post skills you can teach and skills you want to learn
- Match with others for skill exchanges
- Request and schedule sessions
- User profiles and ratings
